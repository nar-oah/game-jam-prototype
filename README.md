# 《任期后生效》玩法验证原型

这是依据 `md/00_README.md`—`md/14_Balance_and_Testing.md` 制作的 Godot 4.6
纯 UI 垂直切片。原型只实现“乳制品生产过剩”事件链，用 3—5 分钟验证：

- 来访者提前但不确定、报纸准确但只剩 3 个月的信息差；
- 主动来访可谈判、主动求援只能接受最终报价；
- 政府、政党、利益集团三类提案的票数与效果分工；
- 60 席议会、31 票过半线、游说票、承诺献金与锁定反对票；
- 法案替换、相同提案保留进度、移除后 CD 清零；
- 独立政策 CD、标签羁绊和实时事件结算预演；
- 彻底解决、推迟到任期后、经济崩溃三种结果。

## 运行

用 Godot 4.6 打开项目后运行主场景，或在项目根目录执行：

```sh
godot --path . --editor
```

主要使用鼠标；`F` 联系金融集团，`V` 表决，`N` 推进一月，`R` 在结算后重开，
`Esc` 关闭非结算浮层。

## 建议测试路线

1. **提前解决**：记录预测，主动联系金融集团，将“最低工资提高 + 工党提案 +
   医药集团 + 金融集团”加入草案，投入 4 点承诺献金，以 31 票通过。长 CD
   政策赶得上，劳动羁绊使危机彻底解决。
2. **晚期延缓**：忽略预测，等报纸确认；在第 43 月谈判农业提案，第 45 月再
   接受金融最终报价。用“工党 + 农业收储 + 金融信贷”凑到 31 票，只能把危机
   延迟到任期之后。
3. **放任失败**：不通过任何法案，推进到第 48 月，崩溃度从 8 升至 10。

规则自动化测试位于 `tests/test_prototype_rules.gd`，覆盖上述三条路线、羁绊以及
法案保留/重置 CD。
